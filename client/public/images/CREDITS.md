## Replacing a photo

Keep the same filename and drop your own file into `/public/images/` — no code changes needed.
Photos are referenced in `src/data/menuData.js` (`image` field) and `src/config.js`
(`heroImage`, `aboutImage`). If a file is ever missing, the site automatically shows the drawn
SVG milk-tea cup instead of a broken image icon.
